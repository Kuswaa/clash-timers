# Squad icons (staging)

64×64 WebP icons for the twelve TH19 squads, from the Supercell Fan Kit (see NOTICE). They are **not
bundled** in the app: only `4000195.webp` (Barch Squad) is, because that is the only squad ID seen in an
export so far.

When a new squad ID shows up (the app's "Unknown items" section lists it, and the widget calls it
`New squad`), copy its file to `app/src/main/assets/icons/<id>.webp` and add the name to
`app/src/main/assets/names_overrides.json`. Don't guess IDs.

Unlock order (IDs likely follow it, 4000196 onwards, but unconfirmed): Barch, Giant & Wizard,
Wall Breaker, Minion, Balloon, Golem & Witch, Hog Rider, Miner, Healer, P.E.K.K.A & Electro Titan,
Dragon, Baby Dragon.
